Grade Calculator
A console program written in C++ for teachers. The teacher types a student's name and 5 scores, and the program shows the student's average and grade. Several students can be entered in one run; at the end the program shows how many students were entered and the class average.
Requirements
The program shall ask for a student's name and accept the word `end` instead of a name to finish the run.
The program shall read exactly 5 whole-number scores (0-100) for each student.
The program shall reject any score outside 0-100 (or a non-number), show an error message and ask for the same score again.
The program shall calculate the average of the 5 scores and show it with one decimal place together with the grade.
The program shall show the number of students entered and the class average at the end, or "No students entered" if there were none.
Grading scale
Grade	Average
A	90 - 100
B	75 - 89.99
C	60 - 74.99
F	below 60
How to run
Open https://www.onlinegdb.com and choose C++.
Paste the code from main.cpp and click Run.
